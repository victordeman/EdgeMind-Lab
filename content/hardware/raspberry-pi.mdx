A Raspberry Pi is a complete Linux computer on a single board with a row of GPIO pins for connecting electronics. In EdgeMind Lab it is the bridge between hardware and software: the same board that switches an LED from Python also runs a local language model and the agent loop that uses it. Labs state which board features they need; check the lab's bill of materials before you start.
