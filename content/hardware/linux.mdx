Every Raspberry Pi lab is done from the Linux command line. Raspberry Pi OS is based on Debian, so the skills practised here carry over to most Linux servers and embedded boards: moving around the file system, editing files, installing packages, managing services and working over SSH. This hub collects the labs that teach or depend on those skills.
