An AI agent is a language model that can call tools and use the results to decide what to do next. The labs in this section build the agent loop in plain Python so each step can be inspected, then give the agent tools that read and control hardware. Each lab sets explicit limits on what the agent may do, because an agent connected to hardware acts in the physical world.
